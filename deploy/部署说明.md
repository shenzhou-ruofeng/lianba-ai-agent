# lianba-ai-agent 宝塔面板部署说明

## 一、压缩包内容

```
deploy/
├── backend/lianba-ai-agent-0.0.1-SNAPSHOT.jar          # 后端主服务（端口 8123）
├── mcp-server/image-search-mcp-server-0.0.1-SNAPSHOT.jar  # MCP 图片搜索服务（端口 8127）
├── frontend/dist/                                   # 前端静态文件（部署为网站根目录）
├── nginx-baota.conf                                 # 宝塔站点 Nginx 配置片段
└── 部署说明.md                                      # 本文档
```

## 二、服务器环境要求

| 组件 | 要求 | 宝塔安装方式 |
|------|------|-------------|
| JDK | **必须 21**（不能用 8/11/17） | 宝塔「Java项目管理器」安装 JDK 21，或手动安装 |
| PostgreSQL | 16 + **pgvector 扩展** | 推荐用宝塔「Docker」跑 `pgvector/pgvector:pg16` 镜像 |
| Nginx | 任意版本 | 宝塔默认已装 |
| 内存 | 建议 ≥ 2G（两个 Java 进程） | - |

## 三、部署步骤（按顺序）

### 1. 上传文件
- 把整个 deploy 压缩包上传到服务器，解压到 `/www/wwwroot/lianba-ai-agent/`

### 2. 启动 PostgreSQL（pgvector 版）
宝塔安装「Docker管理器」，SSH 执行：
```bash
docker run -d --name lianba-pgvector --restart unless-stopped \
  -e POSTGRES_DB=lianba_ai_agent \
  -e POSTGRES_USER=shenzhou_ruofeng \
  -e POSTGRES_PASSWORD=你的数据库密码 \
  -p 127.0.0.1:5432:5432 \
  -v /www/dbdata/pgvector:/var/lib/postgresql/data \
  pgvector/pgvector:pg16
```
> 注意端口绑定 127.0.0.1，不要对公网开放 5432。
> 表和扩展由后端启动时自动创建，无需手动建表。

### 3. 启动 MCP 图片搜索服务（必须先于后端启动）
宝塔「Java项目管理器」→ 添加项目：
- 项目 jar：`/www/wwwroot/lianba-ai-agent/mcp-server/image-search-mcp-server-0.0.1-SNAPSHOT.jar`
- JDK：21
- 启动命令（等效）：
```bash
java -Dfile.encoding=UTF-8 -jar image-search-mcp-server-0.0.1-SNAPSHOT.jar
```
- 端口：8127（仅本机访问即可，无需放行公网）

### 4. 启动后端主服务
宝塔「Java项目管理器」→ 添加项目：
- 项目 jar：`/www/wwwroot/lianba-ai-agent/backend/lianba-ai-agent-0.0.1-SNAPSHOT.jar`
- JDK：21
- 启动命令（等效）：
```bash
java -Dfile.encoding=UTF-8 -jar lianba-ai-agent-0.0.1-SNAPSHOT.jar \
  --spring.profiles.active=prod \
  --DB_PASSWORD=你的数据库密码
```
  （数据库地址默认 `jdbc:postgresql://localhost:5432/lianba_ai_agent`，MCP 默认 `http://localhost:8127`，
   与上面两步一致时无需额外参数；密码也可用环境变量 `DB_PASSWORD` 注入）
- 端口：8123（仅本机访问即可，由 Nginx 反代，无需放行公网）
- 工作目录必须设为 jar 所在目录（`tmp/` 产物目录会生成在工作目录下）

### 5. 部署前端
- 宝塔「网站」→ 添加站点（填你的域名或服务器 IP，PHP 选纯静态）
- 把 `frontend/dist/` 里的**所有文件**（index.html、assets 等）上传到站点根目录
- 站点「设置」→「配置文件」，把 `nginx-baota.conf` 中的内容粘贴进 server { } 块内
  （替换原有的 `location /`），保存后 Nginx 自动重载

### 6. 验证
- 浏览器访问 `http://你的域名/`，能打开首页
- 访问 `http://你的域名/api/health`（健康检查接口）
- 进入「AI 超级智能体」发一条消息，确认流式回复正常

## 四、注意事项（重点看）

1. **启动顺序**：PostgreSQL → MCP(8127) → 后端(8123)。后端 prod 配置强依赖
   MCP SSE 服务，8127 未启动时后端会启动失败或工具不可用。
2. **JDK 必须 21**：用低版本会直接报 `UnsupportedClassVersionError`。
3. **SSE 配置不能省**：Nginx 里 `proxy_buffering off` 等配置去掉后，AI 回复会
   卡住不输出或整段一次性返回。
4. **安全组/防火墙**：阿里云安全组只放行 80/443（和宝塔面板端口），
   **不要放行 8123/8127/5432**，它们只在本机内部通信。
5. **密钥已打进 jar**：DashScope/MinerU/MiMo/SearchAPI/Agnes/Pexels 的 key 都在
   jar 内的配置文件里，请不要把 jar 或本压缩包分享给他人；key 失效时需改
   `application-prod.yml` 重新打包。
6. **HTTPS**：绑定域名后建议在宝塔站点「SSL」里申请免费证书并开启强制 HTTPS，
   前端用的是相对路径 `/api`，无需改代码。
7. **内存不足**：如果 2G 内存吃紧，可给两个 Java 项目加 JVM 参数
   `-Xmx768m`（后端）、`-Xmx256m`（MCP）。
8. **日志排查**：Java 项目管理器里可直接看项目日志；后端启动成功标志是
   `Tomcat started on port 8123 (http) with context path '/api'`。
