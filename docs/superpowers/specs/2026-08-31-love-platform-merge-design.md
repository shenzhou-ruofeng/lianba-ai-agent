# 恋吧AI 产品重构设计方案

## 产品定位

恋吧AI — 垂直情感社交平台。面向 20-35 岁单身/恋爱/已婚用户，以 AI 恋爱大师为核心入口，融合全能工具能力，提供情感咨询、对象推荐、约会规划、图片编辑、报告生成一站式情感生活服务。

## 核心决策

| 决策项 | 结论 |
|--------|------|
| 产品方向 | 垂直情感社交平台 |
| 目标用户 | 20-35 岁，覆盖单身/恋爱/已婚 |
| 商业模式 | 暂不考虑，先跑通功能 |
| 核心断层 | 功能串联断裂（恋爱大师与超级智能体各自为战） |
| 解决方案 | 超级智能体工具全部融入恋爱大师，SuperAgent 页面下线 |
| Prompt 策略 | 情感专家为壳，工具能力按需浮现，结果情感化包装 |
| 日程提醒 | 取消该模块 |
| 图片编辑 | 新增场景，原图直接传给生图模型，不做视觉理解 |
| 前端导航 | 首页 / 恋爱大师 / 我的（去掉超级智能体入口） |

## 产品架构

- 恋爱大师为唯一对话入口，承载所有 AI 能力
- 情感对话、RAG 知识库、对象推荐、恋爱报告、工具调用统一在 LoveApp 中
- 工具层包括：PDF 生成、联网搜索、图片搜索/生成、网页抓取、文件操作、邮件发送等
- 前端页面精简为：首页、恋爱大师、我的（会话管理/个人中心/导出）、登录

## 用户旅程

### 新用户 Onboarding

1. 注册/登录后进入恋爱大师
2. 展示情感状态选择卡片（单身/恋爱/已婚），选择后触发个性化开场白
3. 首次对话后展示能力引导气泡（约会计划 PDF、图片编辑、报告生成等）
4. 引导用户体验工具能力

### 老用户回访

1. 自动恢复最近未完成的会话
2. 对话记忆持久化，AI 能接上上次话题
3. 会话侧边栏支持搜索和历史切换

## 核心用户场景

| 场景 | 用户说的话 | 系统行为 |
|------|-----------|---------|
| 情感倾诉 | "我和女朋友又吵架了..." | 情感对话 + 对话记忆 |
| 知识问答 | "异地恋怎么维持信任？" | RAG 检索知识库回答 |
| 对象推荐 | "帮我推荐一个温柔的女生" | RAG 检索候选人库 |
| 约会计划 | "帮我做一份厦门约会计划" | 联网搜索 + PDF 生成 |
| 图片搜索 | "找一些浪漫的约会图片" | MCP 图片搜索 |
| 图片编辑 | "帮我把这张照片调成暖色调" | ImageGeneration（referenceImageUrl） |
| 图片编辑 | "基于这张合照生成卡通版情侣头像" | ImageGeneration（referenceImageUrl） |
| 图片编辑 | "帮我去掉照片背景，换成海边日落" | ImageGeneration（referenceImageUrl） |
| 报告生成 | "帮我生成恋爱报告" | 结构化输出 + 自动保存 |
| 邮件发送 | "帮我写一封道歉信发给她" | 邮件工具调用 |

## 图片编辑链路

用户上传照片 -> 用户描述编辑需求 -> 调用 ImageGenerationTool（传入 referenceImageUrl + 用户描述） -> 生图模型直接生成 -> 展示原图 vs 编辑后对比 + 下载

前端交互：上传图片后展示缩略图 + 快捷指令气泡（暖色调/卡通版/换背景/去背景）

## 页面结构

| 页面 | 路由 | 状态 |
|------|------|------|
| 首页 | / | 保留，CTA 只指向恋爱大师 |
| 恋爱大师 | /love-master | 升级为主入口，集成全部工具 |
| 我的 | /profile + /export | 保留，增加报告历史入口 |
| 登录 | /login | 保留 |
| 超级智能体 | /super-agent | 移除导航入口，代码保留 |

## 迭代路线图

### Phase 1：融合打通（1-2 周）

- LoveApp 注册全部工具，注入 allTools
- System Prompt 升级（情感专家 + 生活助手）
- 新增 /ai/love_app/chat/tools_sse 接口
- 前端集成工具步骤可视化（tool_step / generated_image / file-list）
- 图片编辑快捷指令气泡
- 移除 SuperAgent 导航入口
- 路由调整（保留 /super-agent 路由兼容旧链接）

### Phase 2：体验打磨（2-3 周）

- 情感状态选择卡片（Onboarding）
- 能力引导气泡
- 用户画像存储（user_profile 表）
- 画像注入 Prompt 实现个性化
- 恋爱报告历史页
- 图片编辑对比展示

### Phase 3：深度功能（3-4 周）

- 情感日记功能
- 关系状态追踪
- 每日情感建议推送
- 知识库扩充（已婚/家庭关系）
- 混合检索全面上线

### Phase 4：商业化准备（远期）

- 付费体系设计
- 用量统计系统
- 会员等级
- 情感社区
